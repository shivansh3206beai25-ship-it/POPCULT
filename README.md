# 🎬 POPCULT - AI Movie Hub

POPCULT is an AI-powered movie discovery web application that helps users find movies based on mood, vibes, aesthetics, and natural language prompts.

Instead of traditional genre filters, POPCULT uses AI recommendations to curate personalized movie suggestions.

---

## ✨ Features

- 🔍 AI-powered movie recommendations
- 🎭 Search movies by vibe or mood
- 🎲 Surprise Me random movie picker
- 🧠 AI Matchmaker quiz for personalized suggestions
- 🎬 Movie trailers inside popup modal
- ⭐ IMDb ratings display
- 📺 Streaming platform availability
- ❤️ Watchlist feature
- 🔐 Demo sign-in system
- 📱 Fully responsive modern UI
- 🌙 Dark mode cinematic design

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Tailwind CSS
- Google Gemini API
- TMDB API
- Lucide Icons

---

## 🚀 How It Works

1. Browse trending movies
2. Search using prompts like:
   - *late night neon drives*
   - *mind bending sci-fi*
   - *movies like Fight Club*
3. AI generates movie recommendations
4. TMDB fetches posters and movie images
5. Click any movie to watch trailer and details
